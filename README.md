# The Challenge: Urgent Review of MaMa CRM

## The situation

The Board of Directors has lost trust in the group running **MaMa CRM**, our self-built CRM system, and has asked for an urgent review against the **Application Review Criteria** presented last quarter.

You have **25 minutes** before the Board meets.

## Your goal

Produce a review of **MaMa CRM** against the Application Review Criteria, ready to hand to the Board. The output format is up to you — a written summary, a scorecard, a set of findings — but it must be defensible and complete enough to inform a Board-level decision.

### Deliverable

Keep your result ready for a **shareback at the end**. Be prepared to say:

- What did you find? (top risks / strengths)
- Which approach did you take, and why?
- What surprised you?

## What's in the workspace

Your LeanIX workspace has everything you need:

- **Application Fact Sheet — MaMa CRM**
  The starting point. Contains lifecycle, ownership, relations, and metadata.
- **Application Review Documentation** (Workspace Files)
  - `Application Review — Top 20 Criteria.pdf` — the criteria you must review against
  - `mama-crm-arc42.pdf` — the architecture documentation for MaMa CRM
  Both files are indexed for the EA Assistant.
- **Application Documentation** (Fact Sheet → Resources tab)
  `mama-crm-arc42.pdf` is also linked directly on the fact sheet.
- **EA Assistant and MCP Server**
  The workspace has both the built-in EA Assistant and an MCP server endpoint. Login details for the MCP server are in your group's workspace file.
